# Brilho & Cia Serviços ✨

Uma landing page moderna em formato de panfleto digital, desenvolvida para divulgação de serviços personalizados de faxina residencial e comercial. O site possui design responsivo, interface limpa e foco em conversão de leads através de um botão de contato direto.

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as tecnologias fundamentais da web, sem frameworks pesados, garantindo um carregamento rápido:

- *HTML5:* Estruturação semântica do conteúdo.
- *CSS3:* Estilização personalizada, layout baseado em Flexbox, efeitos de sombra (box-shadow) e transições dinâmicas.
- *Google Fonts:* Tipografia moderna utilizando a fonte Poppins.

## 🛠️ Principais Recursos

- *Layout Compacto:* Design centralizado com largura máxima de 450px, simulando a estética de um panfleto impresso de alta qualidade.
- *Balão de Destaque:* Uma seção superior em formato de caixa de diálogo para capturar a atenção imediata do visitante.
- *Blocos Informativos:* Estrutura lateral flexível com três variações de cores (#ec4899, #06b6d4, #22c55e) para destacar benefícios ou serviços.
- *Botão CTA Interativo:* Rodapé clicável com link de contato que conta com efeitos fluidos ao passar o mouse (hover) e ao clicar (active).

## 💻 Como Executar o Projeto

1. Baixe ou clone os arquivos do projeto para o seu computador.
2. Certifique-se de que os arquivos index.html e style.css estejam na mesma pasta.
3. Abra o arquivo index.html em qualquer navegador web (Chrome, Edge, Firefox, etc.) ou utilize a extensão *Live Server* do VS Code.
